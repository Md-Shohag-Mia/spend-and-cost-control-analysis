# Spend and Cost Control Analysis Dashboard

An Excel-based procurement analytics project to monitor spending, budget utilization, Maverick Spend, price variance, and supplier performance.

**Tools:** Microsoft Excel, PivotTables, PivotCharts, and Slicers.

**Key KPIs:** Total Spending, Total Orders, Average Order Value (AOV), Total Budget, Maverick Spend (%), and Budget Utilization (%).
